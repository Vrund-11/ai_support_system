# Security Policy

## Supported Versions

SupportPilot receives security fixes on the main branch.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting Vulnerabilities

Report security concerns via email to security@supportpilot.local.
Do not open public GitHub issues for security reports.
Include:

1. Steps to reproduce
2. Impact assessment
3. Proof of concept

Fixes will be addressed within 72 hours.
