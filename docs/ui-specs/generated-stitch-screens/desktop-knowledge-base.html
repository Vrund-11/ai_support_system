To configure SAML 2.0 Single Sign-On (SSO) with Okta, admins must complete the following two steps in SupportPilot Console:

  1. Download SP Metadata & ACS URL: Navigate to Settings > Security > SAML 2.0. Copy the Assertion Consumer Service (ACS) URL and the Entity ID into your Okta Application Integration Wizard. [KB-104 · Chunk #4]
  2. Upload IdP XML Metadata: Export the Okta Application Metadata XML file and upload it into SupportPilot. Ensure that your Okta Network Zone whitelists our static egress IP block 54.210.14.0/24 so background public key rotation succeeds without interruptions. [Guide: Okta Metadata · Chunk #2]
info Just-in-Time (JIT) provisioning is enabled by default. New Okta users will automatically receive the Tier-1 Support Agent role on their first federated authentication.
