Hi Alex, thank you for sharing the ingress payload dumps. I pinpointed the root cause in our cluster router logs:

During yesterday's secondary key rollover at 02:00 UTC, the Stripe signature verification secret on your webhook endpoint was cached with the deprecated hex prefix. The gateway rejected renewals matching the SHA256 digest with an unexpected 403 Signature Mismatch response.

PATCH /v2/webhooks/apex-cloud-stripe 
curl -X POST https://api.apexcloud.io/v2/webhooks/refresh-keys \
  -H "Authorization: Bearer sec_tok_apex_live_891x" \
  -H "Content-Type: application/json" \
  -d '{
    "force_flush": true,
    "target": "stripe_v2",
    "grace_period_sec": 300
  }'

Once flushed via the API endpoint above, the pending retry buffer will automatically ingest queued subscriptions without losing transaction telemetry.
